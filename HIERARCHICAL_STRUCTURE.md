## 🚀 Cara Penggunaan

### Level 1: Pilih Suite
1. Buka aplikasi
2. Lihat 5 suites yang tersedia
3. Klik suite yang sesuai dengan kebutuhan

### Level 2: Pilih Module
1. Lihat modules dalam suite yang dipilih
2. Klik module yang sesuai
3. Gunakan breadcrumb untuk kembali

### Level 3: Pilih Tool
1. Lihat tools dalam module yang dipilih
2. Lihat workflow connections (related tools)
3. Klik tool untuk membuka

### Search
1. Ketik di search bar
2. Lihat hasil pencarian
3. Klik tool yang diinginkan

## 🔧 Technical Details

### Technology Stack
- **Framework:** React 18
- **Styling:** Tailwind CSS
- **State Management:** React Hooks (useState)
- **Type Safety:** TypeScript
- **Build Tool:** Vite

### File Structure
```
src/components/
├── hierarchicalStructure.tsx  # Hierarchical data structure
├── ToolHub.tsx                # Main navigation component
├── [Tool Components]          # 65 individual tool components
└── ErrorBoundary.tsx          # Error handling
```

### Performance
- **Bundle Size:** 1,742.55 kB (gzip: 482.88 kB)
- **Modules:** 578 modules transformed
- **Build Time:** ~13 seconds
