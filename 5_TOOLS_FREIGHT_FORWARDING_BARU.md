## 📋 Daftar 5 Tools Freight Forwarding & Customs Baru

### 1. **Freight Rate Calculator** (Blue) 💰
**Kategori:** Logistics & Customs

**Fungsi:**
- Kalkulator interaktif untuk menghitung total biaya pengiriman
- Input untuk base rate dan berbagai surcharges (BAF, CAF, THC)
- Konversi kurs mata uang (USD, IDR, EUR, SGD)
- Slider target profit margin (0-100%)
- Auto-calculate quotation price untuk klien
- Format currency dalam IDR

**Use Cases:**
- Quotation preparation untuk klien
- Cost analysis untuk shipment
- Profit margin calculation
- Currency conversion untuk international shipments

**Cara Penggunaan:**
1. Buka Freight Rate Calculator
2. Masukkan base rate (USD)
3. Masukkan surcharges (BAF, CAF, THC)
4. Pilih currency dan exchange rate
5. Adjust profit margin slider
6. Lihat hasil calculation (total cost, profit, quotation price)

**Fitur Unggulan:**
✅ Multiple surcharges support  
✅ Currency conversion  
✅ Profit margin slider  
✅ Real-time calculation  
✅ Professional quotation format

### 2. **HS Code Estimator** (Green) 📋
**Kategori:** Logistics & Customs

**Fungsi:**
- Pencarian dummy HS Code (10 sample codes)
- Search by code, description, atau category
- Kalkulator estimasi pajak kepabeanan
- Input CIF value (IDR)
- Input persentase Bea Masuk, PPN, dan PPh impor
- Auto-calculate landed cost
- Breakdown pajak (Bea Masuk, PPN, PPh)

**Use Cases:**
- HS code lookup untuk import/export
- Import duty estimation
- Landed cost calculation
- Tax planning untuk import shipments

**Cara Penggunaan:**
1. Buka HS Code Estimator
2. Search HS Code by code, description, atau category
3. Pilih HS Code dari list
4. Masukkan CIF value (IDR)
5. Masukkan persentase pajak (Bea Masuk, PPN, PPh)
6. Lihat breakdown pajak dan landed cost

**Fitur Unggulan:**
✅ HS Code search  
✅ Tax calculation  
✅ Landed cost estimation  
✅ Tax breakdown  
✅ Sample HS Codes  

**Sample HS Codes:**
- 8471.30.10 - Laptops
- 8517.12.00 - Smartphones
- 6109.10.00 - T-shirts
- 8703.23.40 - Motor vehicles
- 3004.90.99 - Pharmaceutical products

### 3. **CBM Calculator** (Purple) 📦
**Kategori:** Logistics & Customs

**Fungsi:**
- Kalkulator Container Load & CBM
- Form input ukuran barang (Panjang, Lebar, Tinggi, Berat)
- Input jumlah karton/quantity
- Multiple units support (cm, m, inch)
- Auto-calculate total CBM dan total weight
- Rekomendasi kontainer (LCL, 20ft, 40ft, 40HC)
- Container utilization percentage
- Add/remove multiple cargo items

**Use Cases:**
- CBM calculation untuk shipment planning
- Container recommendation
- Load optimization
- Cost estimation berdasarkan volume

**Cara Penggunaan:**
1. Buka CBM Calculator
2. Pilih unit (cm, m, inch)
3. Masukkan ukuran barang (L, W, H)
4. Masukkan berat per carton
5. Masukkan quantity
6. Klik "+ Add Item" untuk tambah item lain
7. Lihat total CBM, weight, dan container recommendation

**Fitur Unggulan:**
✅ Multiple cargo items  
✅ Container recommendation  
✅ Utilization percentage  
✅ Multiple units  
✅ Real-time calculation  

**Container Specifications:**
- **LCL:** Max 15 CBM, 15,000 kg
- **20ft:** Max 33 CBM, 28,000 kg
- **40ft:** Max 67 CBM, 26,000 kg
- **40HC:** Max 76 CBM, 26,500 kg

4. Lihat detail informasi

**Fitur Unggulan:**
