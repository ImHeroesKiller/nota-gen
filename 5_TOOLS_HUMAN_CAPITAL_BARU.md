## 📋 Daftar 5 Tools Human Capital Baru

### 1. **Outsourcing Quotation** 💰
**Kategori:** Human Capital

**Fungsi:**
- Kalkulator billing rate tenaga kerja outsourcing
- Input UMK (Upah Minimum Kota)
- Input persentase BPJS (Kesehatan & Ketenagakerjaan)
- Input persentase THR (Tunjangan Hari Raya)
- Input tunjangan lainnya per bulan
- Input management fee (%)
- Auto-calculate total penawaran per headcount
- Breakdown biaya lengkap (base salary, BPJS, THR, management fee)
- Format currency dalam IDR

**Use Cases:**
- Quotation preparation untuk klien outsourcing
- Cost analysis untuk tenaga kerja
- Profit margin calculation
- Budget planning

**Cara Penggunaan:**
1. Buka Outsourcing Quotation
2. Masukkan jumlah headcount
3. Masukkan UMK per bulan
4. Masukkan persentase BPJS, THR
5. Masukkan tunjangan lainnya
6. Adjust management fee
7. Lihat hasil calculation (total per head, grand total)

**Fitur Unggulan:**
✅ Multiple cost components  
✅ Real-time calculation  
✅ Professional breakdown  
✅ Grand total calculation

### 2. **Timesheet Rekap** ⏰
**Kategori:** Human Capital

**Fungsi:**
- Tabel rekapitulasi kehadiran dan lembur harian karyawan
- Filter by bulan dan klien
- Summary cards (total entries, hadir, jam regular, jam lembur)
- Detail information (tanggal, karyawan, klien, check in/out, status)
- Status indicator (present, absent, leave, sick)
- Color-coded status badges

**Use Cases:**
- Rekap kehadiran bulanan
- Monitoring lembur karyawan
- Billing berdasarkan timesheet
- Reporting ke klien

**Cara Penggunaan:**
1. Buka Timesheet Rekap
2. Pilih bulan yang diinginkan
3. Filter by klien (opsional)
4. Lihat summary cards untuk overview
5. Review detail timesheet di tabel
6. Export untuk billing

**Fitur Unggulan:**
✅ Monthly filtering  
✅ Client filtering  
✅ Summary statistics  
✅ Status tracking  
✅ Detailed table  

---

### 3. **PKWT Contract Builder** 📝
**Kategori:** Human Capital

**Fungsi:**
- Generator draf kontrak PKWT (Perjanjian Kerja Waktu Tertentu)
- Form input lengkap (nama, NIK, posisi, klien, alamat)
- Input tanggal mulai dan berakhir
- Auto-calculate durasi kontrak
- Input gaji pokok
- Input jam kerja dan hari kerja
- Preview kontrak profesional
- Print/Save as PDF functionality
- Edit kembali functionality

**Use Cases:**
- Generate draf kontrak PKWT
- Standardisasi format kontrak
- Quick contract preparation
- Legal documentation

**Cara Penggunaan:**
1. Buka PKWT Contract Builder
2. Isi form input data karyawan
3. Isi data klien dan penempatan
4. Isi tanggal mulai dan berakhir
5. Isi gaji dan jam kerja
6. Klik "Generate Draf Kontrak"
7. Review preview kontrak
8. Print atau Save as PDF

**Fitur Unggulan:**
✅ Complete form input  
✅ Auto-calculate duration  
✅ Professional preview  
✅ Print functionality  
✅ Edit capability  

**Contract Sections:**
- Header dengan kop surat PT Perdana Adi Yuda
- Pasal 1 - Posisi dan Penempatan
- Pasal 2 - Jangka Waktu
- Pasal 3 - Waktu Kerja
- Pasal 4 - Remunerasi
- Pasal 5 - Hak dan Kewajiban
- Signature section

### 4. **Turnover Dashboard** 📊
**Kategori:** Human Capital

**Fungsi:**
- Dashboard visual untuk memantau metrik keluar-masuk karyawan
- Filter by periode (tahun) dan klien
- Summary cards (total join, total resign, turnover rate, net movement)
- Monthly movement chart (visual bar chart)
- Employee movement log table
- Status indicator (join/resign)
- Reason tracking untuk resign

**Use Cases:**
- Monitoring turnover rate
- Analisis keluar-masuk karyawan
- Reporting ke management
- Identifikasi masalah retensi

**Cara Penggunaan:**
1. Buka Turnover Dashboard
2. Pilih periode (tahun)
3. Filter by klien (opsional)
4. Lihat summary cards untuk overview
5. Review monthly movement chart
6. Check employee movement log

**Fitur Unggulan:**
✅ Period filtering  
✅ Client filtering  
✅ Visual chart  
✅ Turnover rate calculation  
✅ Movement tracking  

**Summary Metrics:**
- Total Join (karyawan baru)
- Total Resign (karyawan keluar)
- Turnover Rate (rasio keluar/masuk)
- Net Movement (selisih masuk-keluar)

### 5. **Deployment Planner** ✅
**Kategori:** Human Capital

**Fungsi:**
- Checklist pemenuhan syarat pekerja baru sebelum penempatan
- Multiple deployment tracking
- Category-based checklist (Dokumen, Perlengkapan, Training)
- Progress tracking per category
- Overall completion percentage
- Notes untuk setiap item
- Toggle completion status
- Visual progress bars

**Use Cases:**
- Persiapan deployment karyawan baru
- Tracking kelengkapan dokumen
- Monitoring readiness karyawan
- Quality assurance sebelum penempatan

**Cara Penggunaan:**
1. Buka Deployment Planner
2. Pilih deployment dari dropdown
3. Lihat employee info dan deployment date
4. Review overall completion percentage
5. Check category stats
6. Toggle checklist items
7. Add notes untuk setiap item
8. Monitor progress per category

**Fitur Unggulan:**
✅ Multiple deployments  
✅ Category-based checklist  
✅ Progress tracking  
✅ Notes capability  
✅ Visual progress bars  

**Checklist Categories:**
- **Dokumen:** KTP, NPWP, KK, Ijazah, Pas Foto, SKCK, Surat Sehat, BPJS
- **Perlengkapan:** Seragam, Safety Shoes, Helmet, ID Card Karyawan, ID Card Client
- **Training:** Induction Training, Safety Training, SOP Client
