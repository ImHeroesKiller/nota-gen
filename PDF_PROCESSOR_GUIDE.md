# PDF Processor - Fitur Lengkap

## 🎉 Tool Baru: PDF Processor (Pink)

PDF Processor adalah tool lengkap untuk memproses dan mengedit file PDF dengan 7 fitur utama.

---

## 📋 Fitur Lengkap

### 1. **Compress PDF** 🗜️
**Fungsi:** Mengurangi ukuran file PDF tanpa mengurangi kualitas secara signifikan

**Cara Penggunaan:**
1. Upload file PDF
2. Adjust quality slider (10-100%)
   - Lower = file lebih kecil, kualitas lebih rendah
   - Higher = file lebih besar, kualitas lebih baik
3. Klik "Compress PDF"
4. File akan otomatis ter-download

**Use Cases:**
- Mengurangi ukuran PDF untuk email attachment
- Optimasi PDF untuk web upload
- Menghemat storage space

**Contoh:**
- Original: 10 MB
- Compressed (70%): 3-5 MB

---

### 2. **Merge PDF** 📑
**Fungsi:** Menggabungkan beberapa file PDF menjadi satu file

**Cara Penggunaan:**
1. Upload 2 atau lebih file PDF
2. Klik "Merge PDF"
3. Semua file akan digabungkan sesuai urutan upload
4. File hasil merge akan otomatis ter-download

**Use Cases:**
- Menggabungkan laporan bulanan
- Menggabungkan dokumen kontrak
- Membuat satu file dari beberapa bagian

**Fitur:**
- Support unlimited file
- Progress indicator
- Auto-download hasil

---

### 3. **Add Page** ➕
**Fungsi:** Menambahkan halaman kosong di akhir dokumen

**Cara Penggunaan:**
1. Upload file PDF
2. Klik "Add Page"
3. Halaman kosong akan ditambahkan di akhir
4. File akan otomatis ter-download

**Use Cases:**
- Menambahkan halaman untuk catatan
- Menambahkan halaman tanda tangan
- Menambahkan halaman lampiran

---

### 4. **Rotate Pages** 🔄
**Fungsi:** Merotasi halaman tertentu dengan sudut 90°, 180°, atau 270°

**Cara Penggunaan:**
1. Upload file PDF
2. Pilih halaman yang ingin dirotasi (klik nomor halaman)
   - Klik "Semua" untuk pilih semua halaman
   - Klik "Batal" untuk deselect semua
3. Pilih sudut rotasi:
   - 90° Clockwise
   - 180°
   - 270° Clockwise
4. Klik "Rotate Pages"
5. File akan otomatis ter-download

**Use Cases:**
- Memperbaiki halaman yang terbalik
- Rotasi halaman landscape ke portrait
- Memperbaiki scan yang miring

**Fitur:**
- Select multiple pages
- 3 rotation angles
- Visual page selector

---

### 5. **Delete Pages** 🗑️
**Fungsi:** Menghapus halaman tertentu dari PDF

**Cara Penggunaan:**
1. Upload file PDF
2. Pilih halaman yang ingin dihapus (klik nomor halaman)
3. Klik "Delete Pages"
4. Halaman yang dipilih akan dihapus
5. File akan otomatis ter-download

**Use Cases:**
- Menghapus halaman duplikat
- Menghapus halaman yang tidak perlu
- Menghapus halaman kosong

**Fitur:**
- Select multiple pages
- Visual page selector
- Safe delete (file original tidak terpengaruh)

---

### 6. **Extract Pages** 📤
**Fungsi:** Mengekstrak halaman tertentu menjadi PDF baru

**Cara Penggunaan:**
1. Upload file PDF
2. Pilih halaman yang ingin diekstrak (klik nomor halaman)
3. Klik "Extract Pages"
4. Halaman yang dipilih akan menjadi PDF baru
5. File akan otomatis ter-download

**Use Cases:**
- Mengambil bab tertentu dari buku
- Mengekstrak lampiran dari dokumen
- Membuat ringkasan dari dokumen panjang

**Fitur:**
- Select multiple pages
- Visual page selector
- Auto-download hasil

---

### 7. **Reorder Pages** 🔀
**Fungsi:** Mengubah urutan halaman sesuai keinginan

**Cara Penggunaan:**
1. Upload file PDF
2. Lihat daftar halaman di sidebar
3. Gunakan tombol ↑ dan ↓ untuk mengubah urutan
4. Klik "Reorder Pages"
5. File dengan urutan baru akan otomatis ter-download

**Use Cases:**
- Mengurutkan ulang halaman setelah scan
- Mengubah urutan bab
- Menyusun ulang dokumen

**Fitur:**
- Visual page list
- Drag up/down buttons
- Real-time preview urutan

## 🚀 Cara Menggunakan

### Basic Flow:
1. Buka aplikasi → Pilih "PDF Processor"
2. Pilih operasi yang diinginkan (compress, merge, dll)
3. Upload file PDF
4. Konfigurasi options (jika ada)
5. Klik tombol operasi
6. File hasil akan otomatis ter-download

### Tips:
- **Compress:** Gunakan quality 60-80% untuk balance antara ukuran dan kualitas
- **Merge:** Upload file sesuai urutan yang diinginkan
- **Rotate:** Pilih multiple pages dengan klik satu per satu
- **Delete:** Hati-hati memilih halaman, file original tidak bisa di-restore
- **Extract:** Berguna untuk mengambil bagian tertentu dari dokumen panjang
- **Reorder:** Gunakan untuk menyusun ulang halaman setelah scan

## 🔧 Technical Details

### Teknologi:
- **pdf-lib** untuk manipulasi PDF
- **Client-side processing** (tidak perlu server)
- **No file upload** ke server (privasi terjaga)
- **Fast processing** dengan WebAssembly

### Limitations:
- Max file size: tergantung browser (biasanya 100MB+)
- Password-protected PDF: tidak didukung
- Scanned PDF: compress tidak terlalu efektif
- Image-heavy PDF: compress lebih efektif

### Browser Support:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera
