## 📋 Daftar 5 Tools PDF Baru

### 1. **PDF to Image** (Cyan) 🖼️
**Kategori:** PDF Processing

**Fungsi:**
- Konversi halaman PDF ke format gambar
- Support format PNG dan JPEG
- Pengaturan quality untuk JPEG (10-100%)
- Progress indicator saat konversi

**Use Cases:**
- Konversi PDF ke gambar untuk presentasi
- Extract halaman PDF sebagai gambar
- Membuat thumbnail dari PDF

**Cara Penggunaan:**
1. Upload file PDF
2. Pilih format output (PNG/JPEG)
3. Jika JPEG, atur quality
4. Klik "Convert to Images"

---

### 2. **PDF Watermark** (Violet) 💧
**Kategori:** PDF Processing

**Fungsi:**
- Tambahkan watermark teks ke setiap halaman PDF
- Pengaturan font size (10-100px)
- Pengaturan opacity (10-100%)
- Pengaturan rotation (-90° sampai 90°)
- Pilihan warna watermark
- Pilihan posisi (top/center/bottom)
- Preview watermark real-time

**Use Cases:**
- Tambahkan watermark "CONFIDENTIAL" ke dokumen
- Tambahkan watermark "DRAFT" untuk review
- Tambahkan watermark logo perusahaan
- Proteksi dokumen dari unauthorized use

**Cara Penggunaan:**
1. Upload file PDF
2. Masukkan teks watermark
3. Atur font size, opacity, rotation
4. Pilih warna dan posisi
5. Preview di panel kanan
6. Klik "Add Watermark"

---

### 3. **PDF Page Organizer** (Amber) 📑
**Kategori:** PDF Processing

**Fungsi:**
- Atur ulang urutan halaman PDF
- Move up/down halaman
- Duplicate halaman
- Remove halaman
- Reset urutan ke original
- Reverse urutan halaman
- Visual list dengan nomor halaman

**Use Cases:**
- Reorganisasi halaman setelah scan
- Hapus halaman kosong atau duplikat
- Susun ulang bab dalam dokumen
- Gabungkan beberapa bagian PDF

**Cara Penggunaan:**
1. Upload file PDF
2. Lihat list halaman di panel kanan
3. Gunakan tombol ↑↓ untuk move halaman
4. Klik 📋 untuk duplicate halaman
5. Klik ✕ untuk remove halaman
6. Klik "Reset" untuk reset urutan
7. Klik "Reverse" untuk reverse urutan
8. Klik "Organize Pages" untuk save

---

### 4. **PDF Metadata Editor** (Pink) 📝
**Kategori:** PDF Processing

**Fungsi:**
- Edit title dokumen
- Edit author
- Edit subject
- Edit keywords (comma separated)
- Edit creator application
- Edit producer application
- Baca metadata existing dari PDF

**Use Cases:**
- Tambahkan metadata untuk SEO
- Edit informasi dokumen
- Tambahkan keywords untuk search
- Update author information
- Standardisasi metadata dokumen

**Cara Penggunaan:**
1. Upload file PDF
2. Metadata existing akan otomatis ter-load
3. Edit field yang diinginkan
4. Klik "Save Metadata"
5. File baru dengan metadata updated akan ter-download

---

### 5. **PDF Page Numberer** (Teal) 🔢
**Kategori:** PDF Processing

**Fungsi:**
- Tambahkan nomor halaman ke PDF
- 4 pilihan posisi:
  - Bottom center
  - Bottom right
  - Top center
  - Top right
- 3 format nomor:
  - Number (1, 2, 3...)
  - Page X of Y (Page 1 of 10)
  - Roman (I, II, III...)
- Pengaturan start number
- Pengaturan font size (8-20px)

**Use Cases:**
- Tambahkan nomor halaman ke dokumen
- Buat dokumen formal dengan nomor halaman
- Tambahkan "Page X of Y" untuk referensi
- Gunakan Roman numeral untuk pendahuluan

**Cara Penggunaan:**
1. Upload file PDF
2. Pilih posisi nomor halaman
3. Pilih format nomor
4. Atur start number (default: 1)
5. Atur font size
6. Klik "Add Page Numbers"

## 💡 Tips Penggunaan

### Untuk PDF to Image:
- Gunakan PNG untuk kualitas terbaik
- Gunakan JPEG untuk ukuran file lebih kecil
- Adjust quality sesuai kebutuhan

### Untuk PDF Watermark:
- Gunakan opacity 20-30% untuk watermark subtle
- Gunakan rotation 45° untuk watermark diagonal
- Preview sebelum save untuk memastikan posisi benar

### Untuk PDF Page Organizer:
- Reset urutan jika bingung
- Reverse untuk mirror halaman
- Duplicate untuk halaman yang perlu diulang

### Untuk PDF Metadata Editor:
- Keywords dipisahkan dengan koma
- Title dan Author penting untuk SEO
- Save metadata untuk dokumentasi

### Untuk PDF Page Numberer:
- Gunakan "Page X of Y" untuk dokumen panjang
- Gunakan Roman numeral untuk pendahuluan
- Start number bisa disesuaikan

## 📝 Catatan Teknis

### Teknologi yang Digunakan:
- **pdf-lib** untuk manipulasi PDF
- **Client-side processing** (privasi terjaga)
- **No server upload** (semua di browser)
- **Fast processing** dengan WebAssembly

### Limitations:
- PDF to Image: Masih dalam development (placeholder)
- Password-protected PDF: Tidak didukung
- Scanned PDF: Beberapa fitur mungkin tidak bekerja optimal
- File size: Tergantung browser (biasanya max 100MB+)

### Browser Support:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera
